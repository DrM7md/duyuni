# ديوني — متابعة الديون والأقساط

**🔗 استخدمه مباشرة من المتصفّح:** <https://drm7md.github.io/duyuni/>

تطبيق ويب بسيط (HTML + CSS + JavaScript فقط) لمتابعة الديون من أكثر من جهة — بنك، شخص، شركة — وتسجيل كل دفعة ومعرفة المتبقي وتاريخ الانتهاء من السداد.

- **بلا سيرفر وبلا إنترنت:** افتح `index.html` مباشرة بالنقر عليه (بروتوكول `file://`) أو من الرابط أعلاه.
- **بلا أي مكتبة خارجية:** لا npm، لا build، لا CDN.
- **البيانات على جهازك فقط** في `localStorage`، وتُصدَّر/تُستورد كملف JSON.
- **Mobile First** مع تنقّل سفلي وواجهة عربية RTL، وأرقام لاتينية وتواريخ ميلادية.
- **وعلى الكمبيوتر تخطيط مختلف تمامًا:** قائمة جانبية ثابتة، مساحة عريضة بعمودين، ونوافذ وسط الشاشة بدل الأوراق السفلية.
- **وضع ليلي** تلقائي حسب النظام مع إمكانية فرضه.
- **PWA كامل:** قابل للتثبيت كتطبيق مستقلّ بأيقونته، ويعمل بلا إنترنت عبر Service Worker.
- **المشاركة في السداد (ميزة اختيارية):** إن كان أحد يدفع معك في دين، تعرف كم دفع كلّ واحد وكم بقي على حصّته.

## طريقة التشغيل

**من الجوّال أو أي جهاز:** افتح <https://drm7md.github.io/duyuni/> ثم:

- **أندرويد / Chrome:** قائمة المتصفّح ⋮ ← «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
- **آيفون / Safari:** زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
- **كمبيوتر / Chrome أو Edge:** أيقونة التثبيت ⊕ في شريط العنوان.

بعد التثبيت يعمل التطبيق **بلا إنترنت تمامًا** بأيقونة ونافذة مستقلّة (بلا شريط متصفّح)، ومعه اختصارات سريعة للملخّص والديون والسجل.

**بلا إنترنت:** نزّل المستودع وانقر نقرًا مزدوجًا على `index.html`.

> **مهم:** البيانات تُحفظ في متصفّح الجهاز الذي تستخدمه، لا في المستودع. الرابط والملف المحلّي **مساحتان مختلفتان** — لنقل بياناتك بينهما استخدم تصدير/استيراد ملف JSON من الإعدادات.

> **ملاحظة تقنية:** التطبيق يستخدم سكربتات عادية (`<script src>`) بدلًا من ES Modules لأن `import` يفشل عند فتح الملف من `file://`. هذا مقصود حتى يعمل الملف عند فتحه مباشرة على الجهاز.

## المشاركة في السداد (اختيارية)

**معطّلة افتراضيًّا** ولا يظهر منها شيء في الواجهة. فعّلها من **الإعدادات → ميزات اختيارية → المشاركة في السداد**، وحينها:

1. في نموذج أي دين يظهر قسم **«المشاركون في السداد»**: تكتب اسم كل شخص وتختار نوع حصّته:
   - **نسبة %** — مثال: أحمد 40% من الدين.
   - **مبلغ محدّد** — مثال: خالد اتفق على 12,000 من إجمالي الدين (يظهر لك مقابلها بالنسبة تلقائيًّا).
   - **بلا حصّة** — يساعدك بمبالغ متغيّرة بلا التزام محدّد.

   وزر «قسمة بالتساوي» يوزّع نسبًا متساوية بينك وبينهم.
2. عند تسجيل أي دفعة يظهر سؤال **«مَن دفع هذه الدفعة؟»** — أنت أو أحد المشاركين (الافتراضي: أنت).
3. في صفحة الدين يظهر قسم **«توزيع السداد»**: لكل شخص ما دفعه، وحصّته، والمتبقي عليه، وشريط تقدّمه. وفي «حالة السداد» يظهر **المتبقي على حصّتك أنت**.
4. في **الملخّص** بطاقة **«من سدّد؟»** تجمع ما دفعه كل شخص عبر كل الديون.

| القيمة | الطريقة |
|---|---|
| حصّتك أنت | `إجمالي الدين − مجموع حصص المشاركين` (وتُعرض نسبتها تلقائيًّا) |
| قيمة الحصّة | نسبة: `إجمالي الدين × النسبة` · مبلغ: القيمة كما هي (لا تتجاوز إجمالي الدين) |
| ما دفعه شخص | مجموع الدفعات المسجّلة باسمه (والمبلغ السابق يُحسب على صاحب الدين) |
| المتبقي على حصّته | `قيمة حصّته − ما دفعه` |

**ملاحظات مهمّة:**
- دفعة المشارك تُخصم من الدين كاملًا كأي دفعة — الحصص لا تغيّر إجمالي الدين ولا الأقساط، بل توزّع المسؤولية فقط.
- **الحصّة هدف لا التزام شهري:** الدفعات الفعلية حرّة تمامًا — إن أعطاك 4,000 هذا الشهر و5,000 القادم تسجّل كل مبلغ كما هو، ويحسب التطبيق ما دفعه إجمالًا وما بقي على حصّته ومتوسّط دفعاته وتاريخ آخر دفعة.
- عند تسجيل دفعة لمشارك بحصّة تظهر رقاقة **«باقي حصّته»** لتعبئة المبلغ بضغطة.
- مجموع الحصص لا يُقبل فوق إجمالي الدين، ويمكنك تغيير نوع الحصّة لاحقًا بلا أي أثر على الدفعات المسجّلة.
- مشارك له دفعات مسجّلة لا يمكن إزالته من النموذج قبل حذف دفعاته أو تغيير الدافع فيها.
- **تعطيل الميزة لا يحذف شيئًا:** المشاركون ومَن دفع كلّها محفوظة، تُخفى فقط وتعود كما هي عند التفعيل.

## كيف تُحسب الأرقام

| القيمة | الطريقة |
|---|---|
| إجمالي المستحق | `قيمة القسط × عدد الأقساط` (يُحسب تلقائيًا عند الإضافة) |
| التكلفة الإضافية | `إجمالي المستحق − المبلغ الذي استلمته` (الفوائد والرسوم) |
| المسدَّد | `مبلغ سابق قبل التطبيق + مجموع الدفعات المسجّلة` |
| المتبقي | `إجمالي المستحق − المسدَّد` (لا ينزل تحت الصفر) |
| الأقساط المدفوعة | `المسدَّد ÷ قيمة القسط` (تقريبًا للأسفل) |
| متأخّر | الأقساط التي حلّ موعدها ولم يُغطِّها المسدَّد |
| تاريخ الانتهاء | تاريخ أوّل قسط + (عدد الأقساط − 1) شهرًا |
| موعد التحرّر | أبعد تاريخ انتهاء بين كل الديون غير المسدَّدة |
| صافي الراتب | `(الراتب + دخل إضافي) − مجموع الأقساط الشهرية` |
| نسبة الاستقطاع | `الأقساط ÷ الدخل` — أخضر ≤33%، برتقالي ≤50%، أحمر فوق ذلك |

مواعيد الأقساط تُحسب بالشهر الميلادي مع تثبيت اليوم على آخر الشهر عند الحاجة (31 يناير + شهر = 28/29 فبراير).

## النسخ الاحتياطي (مهم)

البيانات محفوظة في متصفّح هذا الجهاز فقط. إن حذفت بيانات المتصفّح أو انتقلت لجهاز آخر ستحتاج ملف النسخة:

1. **الإعدادات → تصدير نسخة (JSON)** → يُنزَّل ملف باسم `ديوني-نسخة-2026-08-07.json`.
2. على الجهاز الآخر: افتح التطبيق ثم **الإعدادات → استيراد نسخة من ملف**.
3. عند الاستيراد تختار: **استبدال** (يمسح الحالي) أو **دمج** (يضيف غير الموجود فقط بلا تكرار).

إن تعذّر التنزيل (بعض متصفّحات الجوّال) استخدم **مشاركة الملف** أو **نسخ البيانات كنصّ** ثم لصقها في خانة الاستيراد.

### صيغة الملف

```json
{
  "signature": "debt-tracker-backup",
  "schema": 1,
  "exportedAt": "2026-08-07T10:00:00.000Z",
  "settings": { "currency": "QAR", "monthlyIncome": 12000, "otherIncome": 0, "alertDays": 7, "theme": "auto" },
  "loans": [
    {
      "id": "loan_x1",
      "title": "تمويل شخصي",
      "lender": "بنك قطر الوطني",
      "type": "bank",
      "principal": 100000,
      "totalDue": 120000,
      "installmentsCount": 48,
      "startDate": "2026-01-05",
      "openingPaid": 0,
      "partners": [
        { "id": "prt_1", "name": "أحمد", "shareMode": "pct",    "shareValue": 40 },
        { "id": "prt_2", "name": "خالد", "shareMode": "amount", "shareValue": 12000 }
      ],
      "notes": "",
      "archived": false
    }
  ],
  "payments": [
    { "id": "pay_x1", "loanId": "loan_x1", "amount": 2500, "date": "2026-01-05", "payerId": "me", "note": "تحويل بنكي" }
  ]
}
```

- `type`: ‏`bank` أو `person` أو `company` أو `other`
- `principal`: المبلغ المستلم · `totalDue`: إجمالي ما سيُسدَّد · `openingPaid`: ما سُدّد قبل استخدام التطبيق
- `startDate`: تاريخ أوّل قسط
- `partners`: المشاركون في السداد (اختياري) — `shareMode`: ‏`pct` نسبة · `amount` مبلغ إجمالي · `none` بلا حصّة، و`shareValue` قيمتها. (الصيغة القديمة `sharePct` تُقرأ وتُرحَّل تلقائيًّا)
- `payerId`: مَن دفع — `"me"` أو معرّف مشارك من نفس الدين

الاستيراد يمرّ على `store.normalize()` الذي ينظّف كل حقل ويتجاهل الدفعات التي لا يوجد لها دين — فملف ناقص أو معطوب لن يُعطب التطبيق.

## إضافة ميزة لاحقًا

- **حقل جديد في الدين:** أضفه في `store.normalize()` و`store.addLoan()` ثم في `forms/loan-form.js` وأخيرًا في عرض `views/loan-detail.js`.
- **ميزة اختيارية جديدة:** أضف مفتاحها في `blank().settings` و`normalize()`، وصفًّا بـ`switchRow()` في `views/settings.js`، وإجراءً في `app.js`، ثم اجعل كل موضع يظهر فيه محروسًا بشرط المفتاح (كما في `App.store.sharingOn()`).
- **حساب جديد:** ضعه في `core/calc.js` داخل `loanStats()` أو `overview()` — لا تحسب أي شيء داخل ملفات `views/`.
- **شاشة جديدة:** ملف في `views/` + تسجيل المسار في `app.js` + تبويب في `index.html` إن احتجت.
- **لون أو مسافة:** من `assets/css/01-tokens.css` فقط.

GitHub Pages يخدم فرع `main` مباشرة — كل دفع يحدّث الموقع خلال دقيقة، بلا خطوة بناء.

> **مهم عند تعديل الملفات:** ارفع رقم `VERSION` في [`sw.js`](sw.js) (مثلًا `duyuni-v2`) وأضف أي ملف جديد إلى قائمة `SHELL`، وإلّا استمرّ المتصفّح في تقديم النسخة المخزّنة القديمة.
